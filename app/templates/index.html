FastAPI + Python + Web Scraping

Extraer y descargar datos hidrometeorológicos

Ingresa una URL del SENAMHI, pulsa el botón y descarga un archivo ZIP con HTML fuente, tablas extraídas, archivos descargados y metadatos.

Qué contiene el ZIP

  • pages/: una carpeta por página visitada.
  • tables/: CSV generados desde tablas HTML o DOM renderizado.
  • downloads/: archivos detectados o descargados desde la web.
  • metadata/manifest.json: resumen de la extracción.
